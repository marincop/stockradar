# StockRadar

Grok skill for **[marincop/stockradar](https://github.com/marincop/stockradar)** — the only stock repository on this GitHub account.

Install: upload `SKILL.md` (or this folder as a `.zip`) in Grok → Skills, or clone the repo and keep `.grok/skills/stockradar/`.

Invoke with `/stockradar`.

Triggers: stock, ticker, watchlist, TWSE, 台股, 股票, 股市, 看盤, 自選股.
